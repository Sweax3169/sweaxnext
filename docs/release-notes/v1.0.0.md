First public release of SweaxNext, a vocal mix plug-in for rap vocals (VST3, Windows 64-bit).

**Download one of these**

- `SweaxNext-1.0.0-Setup.exe` installs `SWEAX NEXT.vst3` for you only, without admin rights, into `%LOCALAPPDATA%\Programs\Common\VST3`. Choose "all users" in the first dialog to use `C:\Program Files\Common Files\VST3`.
- `SweaxNext-1.0.0-win64-vst3.zip` is the same plug-in without an installer. Copy the `SWEAX NEXT.vst3` folder into one of the folders above.
- `SHA256SUMS.txt` lists the checksums of both.

The installer is not code-signed, so Windows SmartScreen may ask before it runs ("More info" → "Run anyway").

**What's in 1.0.0**

- Listens to the take, measures it phrase by phrase and checks for 22 kinds of problems (pops, harsh esses, noise floor, hum, level jumps, mud, boom and more).
- Builds a chain of up to 20 modules from the findings and the chosen style, renders it offline on the captured take, measures again and adjusts.
- 16 styles: Doğal, Temiz, Trap, Agresif and twelve artist styles. The artist styles describe a vocal sound; the artists are not affiliated with SweaxNext and have not endorsed it.
- Level-matched A/B, DELTA listening, seven macros, module locks, presets, full undo.
- Live, High and Ultra quality modes; latency is fixed per mode and reported to the host.

**Checked before release**

- 159 automated tests pass on a clean checkout (`SweaxTests`).
- pluginval 1.0.4 at strictness 10, including the editor tests.
- Built by GitHub Actions from tag `v1.0.0` with JUCE 7.0.12.
